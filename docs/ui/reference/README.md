# Mantis Studio UI – user-approved visual references

These images are *design references*, not product screenshots or implementation evidence.
All depicted scanner/device status, serials, accuracy figures, temperature, calibration, laser settings, synthetic scans, project files, job progress, plugin availability, remote support, CAD geometry, and measurement results are illustrative. Never claim them as real or supported by mantisd merely because they appear in the artwork.

Original PNG sources were supplied by the user; optimized WebP reproductions are packaged for developer reference. Do not render an entire reference image as the application UI. UI-M0 implements foundational shell and components, not all ten screens.
